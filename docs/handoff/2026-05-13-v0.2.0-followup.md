### Hook 메커니즘 한계 (Anthropic 의존성)

- Claude Code 가 hook reason 표시 시 자동 추가하는 prefix (`"⏺ UserPromptExpansion operation blocked by hook:"`) + suffix (`"Original prompt: ..."`) + 각 줄 2-space indent 는 공식 API 로 제거 불가. `docs.anthropic.com/hooks` 확인 완료.
- 수용 — 시각적 노이즈 작음. 박스 표 본문은 정상 표시됨.

### codex 리뷰 (2회)

1차 리뷰 (origin 만 봤음, 추가 변경 미반영): 5건 발견 → 4건 자동 해결 (추가 변경이 이미 fix) + 1건 (cwd 마스킹) 별도 트랙.

2차 리뷰 (HEAD 변경 직접 확인): 7건 발견 → 4건 수용 + 1건 docstring + 2건 거부 (의도적 동작 / YAGNI).
